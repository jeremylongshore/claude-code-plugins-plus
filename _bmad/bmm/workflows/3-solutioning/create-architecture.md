# Create Architecture Workflow

## Phase
3 - Solutioning

## Agent
Architect

## Purpose
Design the technical architecture based on PRD requirements and break down into implementable epics.

## Prerequisites
- PRD at `_bmad-output/prd/prd.md`

## Steps

1. **Review PRD**
   - Understand all requirements
   - Identify technical implications
   - Note constraints

2. **Technology Selection**
   - Evaluate technology options
   - Select stack with rationale
   - Document decisions

3. **System Design**
   - Component architecture
   - Data model design
   - API design
   - Infrastructure plan

4. **Epic Breakdown**
   - Decompose into epics
   - Define dependencies
   - Estimate complexity

5. **Documentation**
   - Architecture document
   - Tech stack rationale
   - Epic documents

## Output
- `_bmad-output/architecture/architecture.md`
- `_bmad-output/architecture/tech-stack.md`
- `_bmad-output/epics/epic-{n}-{name}.md`
