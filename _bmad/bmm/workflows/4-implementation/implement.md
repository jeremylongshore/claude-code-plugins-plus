# Implement Workflow

## Phase
4 - Implementation

## Agent
Developer

## Purpose
Implement a user story by writing production-ready code.

## Prerequisites
- Story document from `_bmad-output/stories/`
- Architecture reference from `_bmad-output/architecture/`

## Steps

1. **Story Review**
   - Read the story and acceptance criteria
   - Review architecture constraints
   - Plan implementation approach

2. **Implementation**
   - Write clean, well-structured code
   - Follow project conventions
   - Write tests alongside code
   - Handle errors appropriately

3. **Self-Review**
   - Review own code for quality
   - Run tests
   - Check acceptance criteria

4. **Completion**
   - Mark story as implemented
   - Note any deviations or decisions

## Output
- Implemented code with tests
- Updated story status

## Next
Proceed to Code Review workflow
