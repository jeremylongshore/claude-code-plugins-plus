# Plan Sprint Workflow

## Phase
4 - Implementation

## Agent
Scrum Master

## Purpose
Break epics into implementable user stories and organize into sprints.

## Prerequisites
- Epic documents at `_bmad-output/epics/`
- Architecture at `_bmad-output/architecture/`

## Steps

1. **Review Epics**
   - Read all epic documents
   - Understand dependencies
   - Identify implementation order

2. **Story Creation**
   - Break each epic into stories
   - Write acceptance criteria
   - Estimate complexity (S/M/L/XL)

3. **Sprint Organization**
   - Group stories by sprint
   - Respect dependencies
   - Define sprint goals

4. **Documentation**
   - Save individual story files

## Output
- `_bmad-output/stories/story-{n}-{name}.md`

Proceed to Implementation workflow
