# Create PRD Workflow

## Phase
2 - Planning

## Agent
Product Manager

## Purpose
Create a comprehensive Product Requirements Document from analysis artifacts.

## Prerequisites
- Analysis document at `_bmad-output/analysis.md`

## Steps

1. **Review Analysis**
   - Read analysis document
   - Identify key requirements
   - Note any gaps

2. **Define Product Vision**
   - Product vision statement
   - Target audience
   - Value proposition

3. **Document Requirements**
   - Functional requirements
   - Non-functional requirements
   - User stories (high-level)

4. **Prioritize Features**
   - Must-have (MVP)
   - Should-have
   - Nice-to-have

5. **Define Success Metrics**
   - KPIs
   - Acceptance criteria
   - Launch criteria

6. **Write PRD**
   - Compile into PRD document
   - Save to `_bmad-output/prd/prd.md`

## Output
- `_bmad-output/prd/prd.md`
