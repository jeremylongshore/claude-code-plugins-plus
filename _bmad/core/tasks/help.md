# BMAD Help Task

## Purpose
Display BMAD help information and guide users to their next step.

## Steps

1. Read `_bmad/_config/manifest.yaml` to identify installed modules
2. Read `_bmad/_config/bmad-help.csv` for available topics
3. Check `_bmad-output/` for existing artifacts to determine project phase
4. Present relevant help based on current context

## Output
- Current project phase assessment
- Available commands and agents
- Recommended next step
