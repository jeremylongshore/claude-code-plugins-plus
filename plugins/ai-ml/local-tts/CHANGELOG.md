# Changelog

## [1.0.0] - 2026-04-12

### Added
- Initial release
- Text-to-speech via VoxCPM2 (2B params, Apache-2.0)
- 30 language support (auto-detected from text)
- Voice Design mode — describe a voice in natural language
- Voice Cloning mode — clone from 3-10s reference clip
- Ultimate Cloning mode — reference + transcript for max fidelity
- Auto-setup script (creates Python venv, installs dependencies)
- Claude Code plugin packaging (marketplace.json, plugin.json)
- Demo video showcasing all features
