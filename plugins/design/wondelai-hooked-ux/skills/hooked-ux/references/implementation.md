# Hooked -- Habit Loop Implementation Guide

## Overview

Apply Nir Eyal's Hook Model (Trigger, Action, Variable Reward, Investment) to build habit-forming products that drive natural retention.

## The Hook Model

```
TRIGGER --> ACTION --> VARIABLE REWARD --> INVESTMENT
    ^                                          |
    |_________________(next cycle)____________|
```

## Stage 1: Triggers

### External Triggers
- Paid: Ads, sponsored content
- Earned: PR, word-of-mouth
- Relationship: Referral, invitation
- Owned: App icon, email, push notification

### Internal Triggers
The most powerful. User feels an itch, product scratches it.

```markdown
## Internal Trigger Mapping

Emotion users feel just BEFORE opening your product:
- Boredom -> [social feed, games]
- Loneliness -> [messaging, social]
- Uncertainty -> [search, maps]
- Fear of missing out -> [news, social]

What emotion does your product relieve?
Trigger: "When I feel ___, I [open/use product]"
```

## Stage 2: Actions

**Fogg Behavior Model:** B = MAP (Behavior = Motivation x Ability x Prompt)

Increase frequency by reducing friction (ability), not just increasing motivation.

```markdown
## Friction Audit

Steps to first value in your product:
1. ___  [time: ___s]  [friction: High/Med/Low]
2. ___
3. ___

Goal: Remove every step that isn't strictly necessary.
Benchmark: TikTok onboarding = 0 steps to first content.
```

## Stage 3: Variable Rewards

Variable rewards produce compulsive engagement. Three types:

```markdown
## Variable Reward Type Selector

Tribe (social rewards, unpredictable):
- Comments, likes, replies from people they care about
- Good for: social apps, collaboration tools

Hunt (resources, information, unpredictable):
- New items in feed, search results, deals
- Good for: marketplaces, content platforms

Self (intrinsic, mastery-based):
- Achievement badges, level-ups, streaks
- Good for: learning apps, productivity tools

Your primary reward type: ___
How to make it more variable: ___
```

## Stage 4: Investment

User actions that load the next trigger and increase future value.

```markdown
## Investment Audit

What does the user do that:
1. Personalizes the product for them? (e.g., following interests)
2. Creates content/data that raises switching cost? (e.g., saved notes)
3. Invites others into their network? (e.g., shared folders)
4. Signals future intent to use? (e.g., scheduling next session)
```

## Hook Audit Worksheet

```markdown
## Hook Audit: [Feature Name]

Trigger:
- External: [what brings them in?]
- Internal: [what emotional state precedes use?]

Action:
- Simplest action possible: [what is it?]
- Friction level (1-10): ___
- Can be reduced by: ___

Variable Reward:
- Type: Tribe / Hunt / Self
- Is it variable? (not the same every time?) ___

Investment:
- What does user "store" in the product? ___
- How does this make future sessions more valuable? ___
```

## Ethics Check (Eyal's Manipulation Matrix)

```
                    | Would use it myself? |
                    | YES       | NO       |
Does it improve     | YES       | Dealer   | Peddler |
their lives?        | NO        | Entertainer | Pusher |
```

Build in the "Facilitator" quadrant: You use it, it genuinely improves lives.
