# BDE Score

> Multi-factor quantitative stock scoring MCP server

## Description
Self-contained MCP server providing transparent 5-factor quantitative stock analysis. No external API keys required. Fetches real-time market data and computes composite scores (0-100) with signal classification.

## Category
mcp

## Tools
- `analyze_stock` — Score a single stock with 5-factor model
- `analyze_portfolio` — Score and rank multiple stocks
- `get_market_sentiment` — Aggregate market sentiment analysis
- `explain_factors` — Educational explanation of the scoring model

## Requirements
- Node.js >= 20
- Internet access (for market data)
