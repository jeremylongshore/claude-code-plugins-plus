# Mistral AI Skill Pack

> Claude Code skill pack for Mistral AI integration (18 skills)

## Installation

```bash
/plugin install mistral-pack@claude-code-plugins-plus
```

## Usage

Skills trigger automatically when you discuss Mistral AI topics. For example:

- "Help me set up Mistral AI" → triggers `mistral-install-auth`
- "Debug this Mistral AI error" → triggers `mistral-common-errors`
- "Deploy my Mistral AI integration" → triggers `mistral-deploy-integration`
