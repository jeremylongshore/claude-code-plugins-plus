# Langfuse Skill Pack

> Claude Code skill pack for Langfuse integration (18 skills)

## Installation

```bash
/plugin install langfuse-pack@claude-code-plugins-plus
```

## Usage

Skills trigger automatically when you discuss Langfuse topics. For example:

- "Help me set up Langfuse" → triggers `langfuse-install-auth`
- "Debug this Langfuse error" → triggers `langfuse-common-errors`
- "Deploy my Langfuse integration" → triggers `langfuse-deploy-integration`
