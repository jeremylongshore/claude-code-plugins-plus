# Grammarly legacy source database retired

The 24 tutorial templates formerly stored here were retired in the `grammarly-pack`
2.0.0 production rebuild. They contained inaccurate or undocumented API examples and
must not be used to regenerate active skills.

The canonical replacement is `plugins/saas-packs/grammarly-pack/`, with migration
dispositions in its `migration-map.json` and contract evidence in its `000-docs/`.
