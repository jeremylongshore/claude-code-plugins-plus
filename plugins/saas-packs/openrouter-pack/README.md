## Usage

Skills trigger automatically when you discuss OpenRouter topics. For example:

- "Help me set up OpenRouter" → triggers `openrouter-install-auth`
- "Debug this OpenRouter error" → triggers `openrouter-common-errors`
- "Deploy my OpenRouter integration" → triggers `openrouter-deploy-integration`
