# Obsidian Skill Pack

> Claude Code skill pack for Obsidian integration (18 skills)

## Installation

```bash
/plugin install obsidian-pack@claude-code-plugins-plus
```

## Usage

Skills trigger automatically when you discuss Obsidian topics. For example:

- "Help me set up Obsidian" → triggers `obsidian-install-auth`
- "Debug this Obsidian error" → triggers `obsidian-common-errors`
- "Deploy my Obsidian integration" → triggers `obsidian-deploy-integration`
