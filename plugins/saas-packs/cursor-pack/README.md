## Usage

Skills trigger automatically when you discuss Cursor topics. For example:

- "Help me set up Cursor" → triggers `cursor-install-auth`
- "Debug this Cursor error" → triggers `cursor-common-errors`
- "Deploy my Cursor integration" → triggers `cursor-deploy-integration`
