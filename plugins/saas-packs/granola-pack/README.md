## Usage

Skills trigger automatically when you discuss Granola topics. For example:

- "Help me set up Granola" → triggers `granola-install-auth`
- "Debug this Granola error" → triggers `granola-common-errors`
- "Deploy my Granola integration" → triggers `granola-deploy-integration`
