```bash
/plugin install klingai-pack@claude-code-plugins-plus
```

## Usage

Skills trigger automatically when you discuss Kling AI topics. For example:

- "Help me set up Kling AI" → triggers `klingai-install-auth`
- "Debug this Kling AI error" → triggers `klingai-common-errors`
- "Deploy my Kling AI integration" → triggers `klingai-deploy-integration`
