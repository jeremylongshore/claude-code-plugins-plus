# TwinMind Skill Pack

> Claude Code skill pack for TwinMind integration (12 skills)

## Installation

```bash
/plugin install twinmind-pack@claude-code-plugins-plus
```

## Skills Included

### Standard Skills (S01-S12)
| Skill | Description |
|-------|-------------|
| `twinmind-install-auth` | Install Auth |
| `twinmind-hello-world` | Hello World |
| `twinmind-local-dev-loop` | Local Dev Loop |
| `twinmind-sdk-patterns` | Sdk Patterns |
| `twinmind-model-inference` | Model Inference |
| `twinmind-embeddings-search` | Embeddings Search |
| `twinmind-common-errors` | Common Errors |
| `twinmind-debug-bundle` | Debug Bundle |
| `twinmind-rate-limits` | Rate Limits |
| `twinmind-security-basics` | Security Basics |
| `twinmind-prod-checklist` | Prod Checklist |
| `twinmind-upgrade-migration` | Upgrade Migration |

## Usage

Skills trigger automatically when you discuss TwinMind topics. For example:

- "Help me set up TwinMind" → triggers `twinmind-install-auth`
- "Debug this TwinMind error" → triggers `twinmind-common-errors`
- "Deploy my TwinMind integration" → triggers `twinmind-deploy-integration`
