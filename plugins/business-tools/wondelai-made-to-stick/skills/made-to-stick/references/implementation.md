# Made to Stick -- SUCCESs Framework Implementation Guide

## Overview

Apply Chip and Dan Heath's SUCCESs framework (Simple, Unexpected, Concrete, Credible, Emotional, Stories) to make ideas, messages, and explanations stick in memory.

## The SUCCESs Checklist

### S -- Simple

Find the core. What is the single most important thing? Ruthlessly prioritize.

**The commander's intent technique:**
```
Before: "Maximize alignment between cross-functional stakeholders to deliver a cohesive user experience across touchpoints."
After: "Every customer interaction should feel effortless."
```

**Triage test:** Can you explain it in one sentence that a 12-year-old would understand?

### U -- Unexpected

Break a pattern to generate curiosity. Create a gap between what the audience knows and what they need to know.

**Gap-opening techniques:**
1. State what everyone thinks is true
2. Reveal why it's incomplete or wrong
3. Tease the real answer without fully satisfying

**Template:**
```
"Most people think [common belief].
But what actually drives [outcome] is [surprising truth].
Here's why that matters for you..."
```

### C -- Concrete

Use sensory language. Specific > abstract. Names > categories.

| Abstract | Concrete |
|---------|---------|
| "A significant improvement" | "Cut load time from 8s to 1.2s" |
| "Better user experience" | "Users found the button in under 2 seconds" |
| "Increased revenue" | "Added $240k ARR in 90 days" |

### C -- Credible

Use the right kind of proof for the audience.

```markdown
## Credibility Source Selector

Expert audience: Statistics, research citations, methodology
Skeptical audience: Anti-authority ("we're not perfect, but...")
Non-expert audience: Personal story, vivid analogy
Mass audience: Testable credential ("try it yourself")
```

### E -- Emotional

Make them feel something. Facts don't motivate action; emotions do.

**Emotional framing (before/after):**
```
Before: "Our product increases developer productivity by 23%."
After: "Imagine leaving work at 5pm instead of 8pm -- every day."
```

### S -- Stories

Stories are simulation machines. Narrative structure triggers the listener to mentally rehearse the action.

**The Springboard Story (for change):**
```
Protagonist: [like the audience]
Challenge: [the problem they face]
Solution: [how they used the new approach]
Result: [specific outcome -- make it real]
Invitation: [the audience could do this too]
```

## Message Stickiness Audit

```markdown
Rate your message 0-2 per dimension:

Simple (one core idea?) ___
Unexpected (breaks pattern, creates curiosity?) ___
Concrete (sensory, specific examples?) ___
Credible (right source for this audience?) ___
Emotional (makes them feel something?) ___
Stories (narrative structure present?) ___

Total /12. Under 7: rewrite recommended.
```
