# Crossing the Chasm -- Implementation Guide

## Overview

Apply Geoffrey Moore's technology adoption lifecycle to navigate the chasm between early adopters and the mainstream market.

## The Technology Adoption Lifecycle

```
Innovators (2.5%) -> Early Adopters (13.5%) -> [THE CHASM] -> Early Majority (34%) -> Late Majority (34%) -> Laggards (16%)
```

## Stage 1: Identify Your Beachhead Market

The beachhead is a niche with a single compelling reason to buy, a self-contained budget, and references that transfer to adjacent segments.

```markdown
## Beachhead Candidate Scorecard

Segment: [name]

| Criterion | Score (1-5) | Notes |
|-----------|------------|-------|
| Has a "hair on fire" problem we solve | | |
| Can reach them (sales/marketing channel exists) | | |
| Budget owner is identifiable | | |
| References transfer to adjacent segments | | |
| Win probability is high | | |

**Total (max 25):** ___
**Decision:** Pursue / Investigate Further / Pass
```

## Stage 2: Define the Whole Product

The chasm is caused by a product that works for visionaries but lacks the full solution mainstream buyers need.

```markdown
## Whole Product Gap Analysis

**Generic product:** [what you sell today]

**Augmented product gaps (what mainstream buyers need):**
- [ ] Professional services / implementation support
- [ ] Partner integrations (list top 3)
- [ ] Documentation / training materials
- [ ] Compliance certifications: [SOC2, HIPAA, etc.]
- [ ] SLA / uptime guarantees
- [ ] Customer success / onboarding program

**Effort to close gaps:** [High / Medium / Low per item]
```

## Stage 3: Position Against the Specific Alternative

```markdown
## Competitive Positioning Statement

For [target customer persona]
who [has this specific problem],
[Product Name] is a [category]
that [key benefit differentiator].
Unlike [specific competing alternative],
our product [unique capability that matters to this segment].
```

## Stage 4: Distribution Channel Selection

| Mainstream Buyer Type | Preferred Channel |
|----------------------|------------------|
| Enterprise (>1000 employees) | Direct sales + SIs |
| Mid-market (100-999) | Inside sales + channel partners |
| SMB (<100) | Self-serve + resellers |
| Consumer | Retail / app stores |

## Stage 5: Crossing the Chasm Execution

**The bowling pin strategy:** Win the beachhead 100%, use those references to roll into the adjacent pin, and so on.

```markdown
## Bowling Pin Map

Pin 1 (Beachhead): [segment name] -> Target date: ___
Pin 2: [adjacent segment] -> Prerequisite: Win Pin 1
Pin 3: [next adjacent] -> Prerequisite: Win Pin 2
```
