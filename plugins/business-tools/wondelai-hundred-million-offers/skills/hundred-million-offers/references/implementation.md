# $100M Offers -- Implementation Guide

## Overview

Apply Alex Hormozi's offer creation framework to build irresistible offers that command premium prices and minimize sales resistance.

## The Value Equation

```
Value = (Dream Outcome x Perceived Likelihood of Achievement) / (Time Delay x Effort & Sacrifice)
```

**To increase value, either:**
- Increase dream outcome specificity
- Increase perceived success probability (proof, guarantees)
- Decrease time to result
- Decrease effort required from buyer

## Offer Building Blocks

### 1. Identify the Dream Outcome

```markdown
## Dream Outcome Canvas

Customer persona: [name/segment]

What do they WANT? (aspirational): ___
What do they FEAR? (avoiding pain): ___
The ONE result they care most about: ___

Quantify it: "Go from X to Y in Z time"
Example: "Go from 0 to $10k/month in 90 days"
```

### 2. Map the Problem Stack

Every problem has a surface problem and root causes. Solve the whole stack.

```markdown
## Problem Stack (for each desired result)

Level 1 (External problem): "I don't have enough leads"
Level 2 (Internal problem): "I feel embarrassed asking for referrals"
Level 3 (Philosophical): "I believe sales is manipulative"

Your offer should address all three levels.
```

### 3. Create a Solution List

Brainstorm every possible way to deliver the dream outcome:

```markdown
## Solution Brainstorm

Goal: [dream outcome]

Ways to achieve it:
1. ___
2. ___
3. ___
...

Now for each: "What would I need to do/provide so this is GUARANTEED?"
```

### 4. Stack the Value

```markdown
## Offer Stack Builder

Core deliverable: [the main thing]
Bonus 1: [solves problem that would prevent success]
Bonus 2: [speeds up time to result]
Bonus 3: [reduces effort required]
Guarantee: [risk reversal that removes hesitation]

Price anchor: Show value > 10x price
```

### 5. The Guarantee

A strong guarantee removes buyer risk and signals confidence.

| Guarantee Type | Example |
|---------------|---------|
| Unconditional | "100% money back, no questions" |
| Conditional | "Results in 90 days or full refund" |
| Anti-guarantee | "Non-refundable, which means I only take clients I can help" |
| Service guarantee | "Redo it for free until you're happy" |

## Offer Critique Checklist

```markdown
- [ ] Can you state the dream outcome in one sentence?
- [ ] Is the time to result specific? ("in 30 days" not "quickly")
- [ ] Is there proof (case studies, testimonials)?
- [ ] Is there a risk reversal (guarantee)?
- [ ] Does the price feel like a bargain vs. the stated value?
- [ ] Is there urgency or scarcity (real, not manufactured)?
```
