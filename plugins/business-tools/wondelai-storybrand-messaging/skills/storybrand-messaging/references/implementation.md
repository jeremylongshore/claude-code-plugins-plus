# StoryBrand Messaging -- Implementation Guide

## Overview

Apply Donald Miller's StoryBrand (SB7) framework to clarify your marketing message by positioning the customer as the hero and your brand as the guide.

## The SB7 Framework

```
A CHARACTER (hero)
  has a PROBLEM
    meets a GUIDE
      who gives them a PLAN
        and calls them to ACTION
          that results in SUCCESS
            and helps them avoid FAILURE
```

## Building Your BrandScript

### 1. The Character (Hero)

```markdown
Your customer's primary desire:

External desire: "I want to ___ [tangible goal]"
Internal desire: "I want to feel ___ [emotional goal]"
Philosophical desire: "I deserve ___ [justice/worldview]"
```

### 2. The Problem

```markdown
Villain (root cause / external force):
"The villain is [market condition / frustrating process / broken tool]"

External problem: "They can't ___ [observable symptom]"
Internal problem: "They feel ___ [emotion driving the search]"
Philosophical problem: "It's wrong that ___ [injustice they experience]"
```

### 3. The Guide (Your Brand)

Position as guide, NOT hero. Show:

```markdown
Empathy statement: "We understand that [their internal problem]."
Authority: [Evidence you can solve it -- brief, specific]

Examples of authority:
- "We've helped 2,400 companies do this."
- "Our customers save an average of 6 hours per week."
- [Awards / notable clients / case studies]
```

### 4. The Plan

The plan removes confusion and reduces risk.

```markdown
3-step process plan:
1. [Simple, low-barrier first step]
2. [Core action / engagement step]
3. [The transformation/result]

Example:
1. Book a 20-minute call
2. We build your custom setup
3. Watch leads come in automatically
```

### 5. The Call to Action

```markdown
Direct CTA: "Schedule a Demo" / "Start Free Trial" / "Buy Now"
Transitional CTA: "Download the Free Guide" / "Watch the Overview"

Rule: One primary CTA per page.
```

### 6. Success (The Stakes -- Positive)

```markdown
End-state vision:
"Imagine [what their life/business looks like] after working with us."

Make it specific and emotional:
"You spend Friday afternoons with your team instead of manually updating reports."
```

### 7. Failure (The Stakes -- Negative)

```markdown
Cost of inaction (what happens if they don't act):
"Without [solution], [specific negative consequence]."

Use sparingly -- one clear failure statement, not a list of fears.
```

## One-Liner Formula

```
We help [character] do/get [desired outcome] so they can [transformation].

Example: "We help overwhelmed founders automate their reporting so they can focus on what only they can do."
```

## Website Wireframe (SB7 Homepage)

```
[Header]   Logo | Nav links | CTA button
[Hero]     Headline (character + problem) | CTA | Subtext
[Stakes]   "Many companies struggle with X..."
[Value]    3 key benefits
[Guide]    Empathy statement | Authority proof
[Plan]     3-step process
[CTA]      Primary + Transitional
[Social]   Testimonials / logos
[Footer]   
```
