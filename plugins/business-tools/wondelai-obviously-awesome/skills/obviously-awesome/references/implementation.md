# Obviously Awesome -- Product Positioning Implementation Guide

## Overview

Apply April Dunford's positioning framework to ensure your product is understood and valued by the right buyers in the right competitive context.

## The Five Components of Positioning

### 1. Competitive Alternatives

What would buyers do if your product didn't exist?

```markdown
## Competitive Alternatives Discovery

Ask customers: "What would you use instead if we shut down tomorrow?"

Common answers (list yours):
- Spreadsheet / manual process
- [Competitor name]
- Do nothing / live with the problem
- Build it in-house

Key insight: Position against the real alternative, not the obvious competitor.
```

### 2. Unique Attributes (Differentiators)

What do you have that the alternatives don't?

```markdown
## Attribute Inventory

List every capability/feature that matters:
1. ___
2. ___
3. ___

Now filter: Which of these does the competitive alternative lack?
Those are your differentiators.
```

### 3. Value Themes

What value do those differentiators enable?

```markdown
## Value Theme Mapping

Differentiator -> Value it delivers:

"Real-time collaboration" -> "No more version conflicts; decisions made in minutes, not days"
"AI-powered classification" -> "Analysts spend time on insights, not data wrangling"
"On-premise deployment" -> "Passes enterprise security reviews on the first try"
```

### 4. Best-Fit Customer Characteristics

Who gets the most value from those differentiators?

```markdown
## Best-Fit Customer Profile

Buying triggers (when do they urgently need you?):
- ___
- ___

Context that makes your differentiators matter most:
- ___

Anti-customer (who to avoid selling to):
- ___
```

### 5. Market Category

What mental frame puts your value in the best light?

```markdown
## Market Category Selection

Option A: Existing category (easier to understand, harder to differentiate)
Option B: Sub-segment of existing (e.g., "CRM for founders")
Option C: New category (biggest upside, hardest to establish)

Your choice: ___
Reason: ___
```

## Positioning Statement Template

```
For [best-fit customer segment]
who struggle with [specific problem],
[Product Name] is a [market category]
that uniquely [top value theme]
because [key differentiator].

Unlike [competitive alternative],
[Product Name] [specific contrast that matters to this segment].
```

## Positioning Test

Read your statement to a target customer (unfiltered):
- Do they nod? (understood)
- Do they lean in? (interested)
- Do they say "that's different"? (differentiated)

If any of these are missing, revisit the relevant component.
