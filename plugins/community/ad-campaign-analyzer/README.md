# ad-campaign-analyzer

Ad spend diagnostics: statistical-significance checks, budget-waste analysis, winners to scale, and multi-channel budget reallocation from campaign exports. Pure reasoning, no tools.

Part of [goose-skills](https://github.com/gooseworks-ai/goose-skills) — an open-source (MIT) library of 125 growth/GTM skills by [GooseWorks](https://gooseworks.ai). Contributed with attribution; fully standalone.

Install in Claude Code:

```
/plugin install ad-campaign-analyzer@claude-code-plugins-plus
```
