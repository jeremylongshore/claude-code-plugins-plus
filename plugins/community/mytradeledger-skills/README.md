# mytradeledger-skills

Access and manage [MyTradeLedger](https://mytradeledger.com) journaled crypto trades via the REST API.

Install via the trpsbill/skills marketplace:
```bash
/plugin marketplace add trpsbill/skills
/plugin install mytradeledger-skills@trpsbill-skills
```

Source: https://github.com/trpsbill/skills
